Sintaxe PETEQS — referência rápida

Palavras-chave não distinguem maiúsculas de minúsculas e o acento é opcional.

Estrutura

variáveis públicas          { opcional }
    Far, Cel

função nome(entradas: a   saídas: b)
inicio
    resultado <- a + 1     { 'resultado' = valor de retorno }
fim

inicio
    { comandos do programa principal }
fim

Comandos

  • x <- expressão — atribuição
  • leia x / leia a, b — o programa pausa e espera você digitar
  • imprima a, b, "texto" — escreve, sem mudar de linha (os itens são concatenados)
  • imprimaln a, b, "texto" — escreve e muda de linha
  • se cond então … senão … fim se
  • enquanto cond faça … fim enquanto
  • para i <- 1 até N faça … próximo i (ou fim para)
  • Nome(args) ou Nome — chama procedimento/função

Operadores (da maior para a menor prioridade)

  1. não, -, + (unários)
  2. * / mod e
  3. + - ou
  4. = <> < > <= >=

/ entre dois inteiros dá divisão inteira (13 / 2 → 6); com um número real dá divisão real (13 / 2.0 → 6.5).

Vetores e cadeias

  • Índices começam em 1: v[1] <- 10, frase[3]
  • leia frase guarda a cadeia digitada; frase[3] devolve o 3º caractere
  • Literal de vetor: [10, 20, 30]

Funções embutidas

  • ord('A') → 65   ·   chr(65) → 'A'
  • tamanho(texto) / tamanho(vetor) → quantidade de elementos
